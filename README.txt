Isi folder:
- index.php       : halaman utama dan contoh pembuatan object
- Kendaraan.php   : class Kendaraan
- Pelanggan.php   : class Pelanggan

Cara menjalankan:
1. Pasang PHP atau XAMPP.
2. Salin folder source_code ke folder htdocs jika menggunakan XAMPP.
3. Jalankan Apache dari XAMPP.
4. Buka http://localhost/source_code/index.php di browser.

Catatan:
Project ini adalah contoh praktikum dasar PBO. Data kendaraan dan pelanggan masih
disimpan langsung di kode, belum menggunakan database.
